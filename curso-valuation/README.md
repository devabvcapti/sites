# Valuation — Landing Page (ABVCAP)

Sales landing page for ABVCAP's "Valuation" course, built with Next.js.

## Getting started

```bash
npm install
npm run dev     # local dev server
npm run test     # unit tests (Vitest)
npm run build    # production build
```
